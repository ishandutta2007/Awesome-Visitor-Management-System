# Awesome-Visitor-Management-System

### Top Visitor Management Systems Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**
*Focused on Digital Lobby Check-In, Badge Printing, Host Notifications, Compliance & Workplace Security*
**Last updated: August 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Visitor Management Systems**. These tools digitize front-desk operations: pre-registration, self-service kiosk check-in/out, photo badges, NDA signing, host notifications (email/SMS/Slack/Teams), watchlists, real-time visitor logs, evacuation mustering, and integrations with access control and workplace platforms.

**Examples** include Envoy, Proxyclick (Eptura Visitor), HID Visitor Manager, The Receptionist, Eden Workplace, SwipedOn, Sign In App, Veris Welcome, Traction Guest / Sign In Solutions, and Archie (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom kiosk flows, badge printing, notifications, and open visitor data processing — ideal for offices, campuses, factories, researchers, and developers building transparent, privacy-focused visitor solutions.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## Open-Source GitHub Projects

- **[VisitorPortal](https://github.com/P0etInc0de/VisitorPortal)**  
  Production-oriented Laravel visitor management portal with pre-registration, reception check-in/out, PDF badge printing, welcome monitor displays, email notifications, role-based access control, optional MFA, and OpenID Connect SSO.

- **[FrontDesk](https://github.com/prodstarter/frontdesk)**  
  Open-source Laravel + Filament visitor management system for digital check-ins, visitor details management, customizable workflows, real-time tracking, and GDPR-friendly data handling.

- **[T.C.E.D.I. Open Visitors Management System (tcedi-ovms)](https://github.com/tcedi/tcedi-ovms)**  
  Free Apache-licensed web-based system for visitor check-in, optional NDA signing, direct badge printing, check-out, receptionist monitoring, virtual keyboard for touchscreens, and basic reporting.

- **[VMS (Golang)](https://github.com/Xanik/VMS)**  
  Visitor management system written in Go with employee registration, guest visit codes, and email/SMS notifications.

- **[VisiTrack](https://github.com/gerardocipriano/VisiTrack-VisitorManagement)**  
  ASP.NET Core + Entity Framework + Vue + SignalR visitor management system for registering visitors in/out of a facility with real-time capabilities.

- **[visitor-management (nikramakrishnan)](https://github.com/nikramakrishnan/visitor-management)**  
  Classic PHP/MySQL visitor management system with admin login, visitor logging, and documentation.

- **[visitor-management-system (chttrjeankr)](https://github.com/chttrjeankr/visitor-management-system)**  
  Flask + MongoDB check-in/check-out portal with host details, automatic timestamps, and admin database view.

- **[VMS (ParshwaS)](https://github.com/ParshwaS/VMS)**  
  MEAN-stack visitor management system with WhatsApp bot registration, QR codes, entry/exit tracking, and admin/guard panels.

- **[WRL-Visitorpass](https://github.com/Varunyadavgithub/WRL-Visitorpass)**  
  Full-stack MERN visitor pass system with JWT auth, QR-based A4 printable passes, photo uploads, and real-time gate monitoring (enterprise/factory oriented).

- **[visitor-management-system (blankcry)](https://github.com/blankcry/visitor-management-system)**  
  React + Node.js (Express) + PostgreSQL visitor management system with JWT authentication.

- **[Receptio](https://github.com/mkotson/receptio)**  
  Complete free visitor management solution with email/SMS alerts, photo badges, electronic visitor log, motion/face detection greetings, and MailChimp integration.

- **[Geofencing-for-Visitor-Management-Systems](https://github.com/ElectrifyCS/Geofencing-for-Visitor-Management-Systems)**  
  Python-based location verification engine for visitor systems that detects GPS spoofing using multi-factor anomaly detection, Kalman filtering, and badge/RFID correlation.

### Additional Strong Open-Source Options

- **PHP/Laravel & Filament** visitor portals and badge printers (many student and production forks of VisitorPortal / FrontDesk style projects).
- **Node.js / React / MERN** check-in dashboards and QR pass generators.
- **ASP.NET Core + Vue/React** real-time visitor tracking apps.
- **Go and Python** lightweight visitor registration and notification services.
- **Android / mobile** visitor check-in apps paired with backend APIs.
- Community **kiosk + printer** integrations, NDA e-signature flows, and evacuation list generators.
- Many campus/factory-specific **gate pass** and **entry-exit** systems on GitHub.

**Frameworks for building custom systems**: Combine **Laravel/Filament** or **Node.js + React**, **PostgreSQL/MongoDB**, **QR code libraries**, **PDF badge generators**, **email/SMS gateways**, **InfluxDB + Grafana** for occupancy analytics, and optional **Ollama** or rule engines for intelligent screening and host matching.

## Disclaimer

- This is a **community-curated** list — not exhaustive and not an endorsement.

- Self-hosted open-source solutions require proper security hardening, data retention policies, backups, and reliable hardware for kiosks/printers.
